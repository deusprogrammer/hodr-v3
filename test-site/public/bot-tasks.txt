ACCESSIBILITY PLAYGROUND: BOT TASKS

Rules for the bot:
Use only the accessibility tree to discover content, names, roles, values,
states, and relationships. Interact using accessible roles/names and keyboard
actions. Do not inspect HTML, CSS selectors, application code, or hidden state.
Verify each result using visible or accessibility-tree content.
Use fictional information only.

Setup:
Start on the Playground page for each independent task. Reload between tasks
unless a task explicitly asks you to keep working with its existing state.
All state is local to the current page. Reloading or following a link to
another page resets it. Support submissions do not contact a real server.
Date and time inputs may have browser-specific accessible subcontrols; use
their labels and keyboard controls rather than relying on a visual format.
